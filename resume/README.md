Phone-free copy of the resume, kept in the repo so the version the site hands
out is version controlled.

The only change from the original is the deleted phone number in the heading.

To produce the PDF the site serves:

  1. Compile prashant-yadav-resume.tex (Overleaf: upload, Recompile, Download PDF).
  2. Save the result as  public/prashant-yadav-resume.pdf

The download link on the Contact page appears only when that file exists, so
until it is there nothing on the site is broken or points at a missing file.
